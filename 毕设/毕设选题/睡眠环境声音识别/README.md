# 睡眠环境声音识别：数据与实施计划

状态：拟题与计划阶段；未下载数据、训练模型或验证硬件。目标是在导入的录音中识别有限类别的声音并展示事件时间，不判断是否入睡或事件是否造成干扰。

## 升级后的毕设大纲（计划，待导师确认）

建议题目：《面向睡眠环境的声音事件检测与抗干扰方法研究及系统实现》。原拟题是否需要更改由导师和学校流程决定。

### 研究目标和成果范围

以敲门、脚步、闹钟为试点，对导入的录音识别事件类别及时间区间，研究背景噪声与距离变化对检测的影响。系统提供导入、事件时间线、分类筛选、音频回听和统计导出。时间轴默认是相对录音起点的时间；用户提供录音起始时刻后才能显示实际时钟时间。

研究主问题：使用背景噪声和音量变化的数据增强，能否提高独立房间录音中的事件检测表现，同时控制误报？这是一项待验证的研究假设，不预设改进有效。数据增强采用同一模型、同一训练/验证/测试划分，与未增强对照；增广参数和检测阈值只用训练/验证集确定。

必做：数据审查与标注、短音频分类基线、目标事件定位、增强前后对照、分场景评测和可回听原型。可选：多个事件重叠检测、更多声音类别、实时录音及手机适配；仅在核心功能完成且数据、时间允许时开展。报警识别不等于安全认证，统计次数不能解释睡眠质量或健康风险。

### 数据与实验设计

1. 根据实际可下载情况核实公开数据：ESC-50用于片段分类；TAU-SEBin优先核实时间标签与目标类别；DESED作为候选，先核对标签映射和获取条件。先做数据清单和数据授权审查，不将弱标签当成事件起止标签。
2. 自录试点：目标三个或以上独立场景/录制批次、每类至少20个事件，同时录制安静背景、非目标声音；记录设备、距离、背景和时长。该数值只是试点目标；按类别、场景和独立事件数检查不足，按需要补录，无法预先保证统计充分。
3. 先按原始录音、房间/场次划分训练、验证和独立测试，再切片、合成和增强；不同数据集若共享源音频要核查，不能用测试数据合成训练样本。抗干扰测试优先使用独立房间及录音设备条件，若无法同时隔离两者需明确限制。
4. 模型对比：MFCC+SVM基线与梅尔频谱+轻量CNN；采用相同目标类别和数据划分，长录音检测使用同样的切窗、合并与评价流程。基线与CNN比较是方法选择；增强与否的同模型对比才是主研究实验。若资源不足，评估预训练音频特征的授权、资源和与测试集重叠风险。
5. 评估：短片段报告宏平均F1和各类召回；主实验报告独立场景的事件级F1及逐类表现，同步报告每小时误报数、录音时长和每类真实事件数。研究假设是否得到支持，依据事先设定的独立场景对照及误报变化，不以个别例子代替整体结果。背景噪声和距离分别描述条件与结果，数据太少仅称探索。
6. 时序评分：预测与同类标注一对一匹配，区间IoU≥0.3作为拟定探索门槛；P=匹配事件数/预测事件数，R=匹配事件数/真实事件数，F1=2PR/(P+R)。门槛必须在最终测试前确认并报告，短促声音的边界不确定性需在误差分析中讨论。阈值在验证集选定，不用最终测试集调优；匹配前合并切窗预测，静音和未知声音也须纳入误报评估。

## 数据能否支撑

- [ESC-50](https://github.com/karolpiczak/ESC-50)：2,000段、50类、每类40段、每段5秒；有敲门、脚步、闹钟、狗叫等。适合片段分类基线，不提供事件起止时间，也不等同于夜间卧室长录音。类别未必包含关门或一般说话，不能把敲门当关门。非商业许可，下载和使用前核对具体条款。
- [TAU-SEBin](https://researchportal.tuni.fi/en/datasets/tau-sebin-binaural-sound-events-2021/)：模拟房间声景，包含敲门、脚步、说话等，提供事件起止标注；有单声源和最多两个事件重叠的子集，可作为定位评测候选。其模拟数据不能代替真实卧室录音；下载可用性、类别分布及许可仍待核实。
- [DESED](https://github.com/turpaultn/DESED)：家居场景事件检测候选，部分数据带事件起止标注；使用前核对具体版本、目标类别、下载和许可，不预设覆盖敲门与脚步。
- 自录：模拟卧室或宿舍，包含目标事件和无目标事件背景，记录起止时间；这是测试真实场景的重要补充，不是公开数据已具备的内容。

## 指标卡

| 问题 | 主指标和口径 | 数据与对照 | 判断边界 |
|---|---|---|---|
| 短音频能否分对类别 | 各目标类宏平均F1；逐类精确率、召回率及混淆矩阵辅助解释 | ESC-50同一类别和官方fold，比较MFCC+SVM与梅尔频谱+轻量CNN | 每类仅40段，不代表卧室效果；按官方fold防同源泄漏 |
| 录音中事件能否找对 | 事件级F1：同类预测与人工标注一对一匹配，区间交并比IoU≥0.3视为命中，P=命中/预测事件数、R=命中/标注事件数、F1=2PR/(P+R) | 有起止标注的自录留出测试；两种模型使用相同窗口、合并和匹配规则 | IoU 0.3为探索约定，需在结果前确认；同时报告逐类结果、每小时误报数及持续时长 |
| 实用性 | 安静和未知声音中每小时误报事件数；回听可定位 | 含背景与非目标声的独立自录 | 不宣称整夜可靠或医学效果 |

训练、阈值选择、最终测试独立；自录按录制场次、空间或设备分组，禁止同一录音切片跨集合。公开数据训练、合成训练及留出测试若共享源音频，会造成泄漏；先按源音频分组，再制作样本。测试集只在配置确定后评估。重叠事件分别按类别标注；当前单标签模型对重叠限制明显，先测单主事件并将重叠列为单独探索，不能声称已解决多标签。

## 计划实施

1. 数据可用性：核实ESC-50类别及fold，试下载并试听；检查TAU-SEBin下载、大小、许可、时序标注及源数据划分。未核实前不承诺可用。
2. 锁定范围：优先敲门、脚步、闹钟3类，加入真实背景/非目标负样本；关门、说话列为待补数据的候选，不冒充ESC-50已有类别。敲门与关门分开标注。
3. 小规模自录：拟采集3个及以上不同房间或设备/录制场次、每类至少20个事件，并记录安静背景和其他声；这是可行性试点目标，不是统计充分的保证。标注开始/结束时间、类别、场次与环境，不记录私人对话内容；参与者同意。
4. 构建短片段基线（MFCC+SVM）和主要方法（梅尔频谱+轻量CNN，资源不足先评估轻量预训练特征的条件及数据重叠）。使用相同划分，报告宏F1及逐类结果。
5. 固定滑动窗、步长、置信阈值与相邻窗口合并规则，建立长音频时间线；阈值只用验证集选择，最终集仅用于报告。报告事件级F1与每小时误报；交互结果表示时间区间而非精确到毫秒。
6. 打包导入录音、结果时间线及片段回听，留存复现说明和错误案例；本地录音时间默认从0开始，真实时钟时间需用户提供起点。

## 决策节点和风险
