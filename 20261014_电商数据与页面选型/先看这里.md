## 字段含义

| 实际Excel表头 | 官方说明中的字段 | 含义 |
|---|---|---|
| Invoice | InvoiceNo | 订单或交易单号，C开头表示取消交易 |
| StockCode | StockCode | 商品编号 |
| Description | Description | 商品描述 |
| Quantity | Quantity | 该商品在该交易中的数量 |
| InvoiceDate | InvoiceDate | 交易日期与时间 |
| Price | UnitPrice | 单价，英镑 |
| Customer ID | CustomerID | 客户编号 |
| Country | Country | 客户所在国家 |

两张表的实际表头完全一致，上表逐项列出与官方说明的命名对应。每条记录为交易明细，不等于一笔独立订单；8列中不包含原始库存、采购成本、浏览量或点击记录。
