# 预测曲线重复生成与刷新修复

问题：预测任务及表格成功，图表区域在再次生成后空白。当前代码将预测结果置空时会移除图表DOM，但仍缓存旧ECharts实例；新结果渲染后继续更新已经移除的旧容器。

修复：图表实例绑定当前容器，容器移除时释放；在Vue完成DOM更新后观察容器与结果，再初始化/更新图表；用ResizeObserver同步侧栏及窗口变化，离开页面时断开观察与释放实例。

本轮还按用户要求生成系统目录的“登录配置.ini”，只保存已验证的本机登录信息，不作为密码重置入口。该文件加入.gitignore，验证记录不包含口令。

本轮使用Claude Code文件读取/编辑工具应用修改；Codex负责设计、复核与验收，不将工具文件编辑冒称Claude模型独立实现。Windows Computer Use原生通道不可用，页面回归使用独立的无头浏览器测试。

验证目标：连续生成不同日期的预测、刷新恢复、页面切换恢复后，当前DOM中的曲线都能绘制；容器尺寸变化后画布同步，控制台无图表相关异常。专用脚本、构建日志与截图集中保存本包。

## 实际结果

- Vue类型检查与原生配置加载器生产构建通过，见`typecheck.log`、`build.log`。新`dist`已经提供给当前8777服务，后端无需重启。
- 使用独立无头Edge上下文运行`check_chart_refresh.mjs`，7项真实页面检查全部通过，0个页面异常：恢复已保存结果、生成2011-07-05及07-06预测、侧栏切换、响应式缩放、刷新、离开订单页后返回。每项检查均读取当前DOM画布的实际绿色曲线像素，不以“任务成功”或存在空画布代替绘图成功。
- 两次重新生成时旧容器确实被移除，当前实例编号依次变化，画布宽度随后随布局从872更新到990和918像素。详见`browser_results.json`、`browser_test.log`。
- [连续生成后的预测曲线](预测曲线_连续生成后.png)已人工查看，包含绿色预测和灰色实际曲线。
- 本地管理员和运营账号均用独立会话实际登录成功后写入“电商运营系统/登录配置.ini”，随即退出验证会话；没有重置密码或退出用户已有会话。日志不包含口令，配置文件已加入.gitignore。

测试依赖：`npm install --no-save --no-package-lock --ignore-scripts playwright-core@1.56.0`，使用本机已安装Edge；依赖仅在本测试包的忽略目录内。复现命令：`node check_chart_refresh.mjs`。测试会创建两次真实预测任务并改变当前批次最近成功结果，不修改模型、订单或库存。
