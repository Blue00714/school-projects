# 原型演示步骤（课程答辩/验收用）

演示日期：2026-10-29。对象：FastAPI 课程原型。演示前请确认“已知限制”并如实说明：真实大模型 API 未接通，库存为模拟数据。

## 0. 准备

```powershell
cd 电商运营系统
python run.py --port 8777
```

- 打开 `http://127.0.0.1:8777`（接口文档 `http://127.0.0.1:8777/docs`）。
- 首次启动会生成一次性账号口令，查看 `runtime/initial_admin.txt`（管理员 admin、运营 operator）。
- 若 8777 被占用，换端口即可；演示前建议关闭其他占用进程。
- 想从干净状态演示：备份后删除 `runtime/app.sqlite3` 与 `runtime/batches/`（**不要**删 `retail.sqlite3` 和 `models/`），重启会重新初始化账号与批次登记。

## 1. 登录与权限（约1分钟）

1. 打开页面 → 登录页，输入管理员账号口令 → 进入主界面。
2. 指出顶部：当前用户/角色、当前数据批次（原始数据 2009-12-01~2011-12-09）。
3. 用运营账号再登录一次，打开 `/api/users` 或“系统管理”页：提示无权限（后端 403，不是只隐藏菜单）。
4. 退出后直接访问业务接口：返回 401。说明会话由 HttpOnly Cookie + 服务端会话表维护。

## 2. 看板与订单（约2分钟）

1. 看板选 2011-11-10 ~ 2011-12-09，展示：
   - 销量 **851,403 件**、销售额 **£1,694,068.71**、订单 **2,913**、明细 **86,861** 行；
   - 日趋势、同长度前期对比、商品排名、国家汇总；
   - 质量提示与口径警告。
2. 强调：这是历史实际值，与交接清单的历史对照逐项一致；销售额≠利润；无记录日补0只是构造连续销量。
3. 商品与订单页：订单总数 2,913 与看板一致；点开一单，明细行数量/金额相加等于订单头。
4. 导出趋势 CSV：UTF-8 BOM、字段与页面一致。

## 3. 数据导入与批次切换（约3分钟）

1. 数据导入页上传 `runtime/batches/` 之外的一个小样例（8 行 CSV/20 行 xlsx）→ 提交后立即返回任务标识（异步），页面显示“处理中”。
2. 处理完成：展示质量报告（原始行/保留行/正向销售/跨表副本/取消/非正数量/缺价等）与问题清单。
3. **同一文件再上传一次**：状态为 `duplicate`，不新增数据（按 sha256 判重）。
4. 在批次列表点“切换为当前批次” → 看板变为该批次范围（示例 46 件 / £135.5 / 6 订单）；超出该批次日期的查询显示覆盖警告，而不是旧数据。
5. 切回 `original` → 历史窗口数字恢复 851,403。强调：导入处理期间旧批次仍可查，预测任务绑定创建时批次。

## 4. 预测与回测（约2分钟）

1. 预测页：模型选“周季节与LightGBM组合”，起点 2011-12-09，提交 → 轮询到成功，展示未来 7 天（2011-12-10~16）预测、基准、WAPE/MAE/偏差与警告。
2. 指出：7 行 `actual` 为空（未来无真实值不评分）；历史零销量星期是候选规则，不是已确认歇业；组合模型可能因数据不足明确回退并标注。
3. 回测：选 2011-11-01~11-03，提交 → 展示可评分条数、WAPE、基准对比；说明重叠起点不是独立样本。
4. 下载结果 CSV：含 origin/模型版本/数据政策版本/批次 id。

## 5. 模拟库存（约3分钟）

1. 库存页新建场景（模拟），为商品设置：初始库存 100、提前期 8 天、安全库存 30、日需求 10。
2. 依次入库 20 → 余额 120；出库 30 → 余额 90；**重复提交同一出库**（相同幂等键）→ 仍为 90，不重复记账；尝试出库 91 → 被拒绝并提示当前余额。
3. 补货建议：提前期需求 80 + 安全库存 30 − 当前 90 − 有效在途 10 = **候选 10**，页面展示公式与“模拟”标识。
4. 确认补货 10（登记在途，不直接加库存）→ 到货入库 → 余额 100。
5. 强调：库存是人工模拟场景，历史交易不会自动扣减为真实库存。

## 6. AI 助手与简报（约2分钟）

1. AI 页顶部横幅：**未配置真实大模型**，当前为本地规则工具层。
2. 提问“2011-11-10到2011-12-09全店卖了多少” → 回答含 851,403 件 / £1,694,068.71 / 2,913 单，并显示工具调用轨迹与“未调用大模型”声明。
3. 提问无日期的问题 → 使用默认范围并在答案中写明范围；问题无法映射时给出追问。
4. 生成运营简报 → 下载 Markdown：含数据范围、批次、关键指标、预测局限、模拟标识。
5. 强调：数字全部来自服务端工具；无密钥不伪造 AI 结果；AI 只读，库存变更必须走页面确认。

## 7. 失败路径与边界（约1分钟）

- 未登录访问业务接口 → 401；运营访问用户管理 → 403；跨源写请求 → 403。
- 未知接口（已登录）→ 404；非法参数 → 400 且错误体含 `error`/`code`。
- 导入缺列/伪 xls/超大文件 → 失败并写明原因；`.xls` 当前不支持（提示另存为 .xlsx）。
- 预测未知模型/越界起点 → 400；任务失败时状态明确，不会一直“运行中”。
