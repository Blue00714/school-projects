# 智能电商运营管理系统 · 原型说明（v0.2.0-prototype）

> **本系统当前是课程可运行原型（雏形），不是"系统完整交付"。**
> 六个模块的接口、页面与自动化测试已在 FastAPI 上真实跑通，但**真实大模型 API 未接通**，AI 部分只能记为"待真实 API 验收"；性能未做完整 P95 验收；报告后文章节、接口文档定稿与答辩 PPT 未随原型更新。

本文件是原型的范围、边界、启动方式、账号与配置说明和已知限制入口。接口约定以 [API契约.md](../电商运营系统/docs/API契约.md) 为唯一依据。

## 1. 原型范围与边界

| 模块 | 已实现 | 性质与边界 |
|---|---|---|
| M1 认证与权限 | 登录/退出/改密；管理员与运营人员两角色；后端校验（非只隐藏菜单）；账号启停；`/docs` 与 `/openapi.json` | 后端真实校验 401/403；首次启动生成一次性初始化凭据；无公开注册 |
| M2 数据导入与看板 | `.xlsx`/`.csv` 异步导入、质量报告（缺列/非法日期/数量/单价/取消/重复候选）、同文件 `duplicate`、批次快照与显式切换；看板、商品检索、订单列表与明细、交易明细、三类 CSV 导出 | 导入是**原型级"每批一个完整快照 + 显式切换"**，不做跨文件增量合并、不提供回滚界面；`.xls` 因环境缺 `xlrd` 会失败，请用 `.xlsx`/`.csv` |
| M3 预测与回测 | 全店未来 7 天；5 种方法（含组合与 LightGBM）；历史回测；任务排队/持久化/重启可查；结果与 CSV 导出；任务绑定创建时批次；防未来信息泄漏 | 复用既有 `services/forecasting.py` 算法与口径，未重新开发或调参；预测不随看板筛选自动改变；不把零销量星期称为已确认非营业日 |
| M4 模拟库存 | 场景、商品参数、入库/出库流水、余额事务、幂等提交、有效在途、补货候选、确认在途与到货入库；全响应 `simulated: true` | **全部为人工模拟输入**，不由历史交易自动扣减，不代表真实库存；全店预测不自动分摊成 SKU 需求 |
| M5 AI 助手 | 只读工具层（看板/商品/订单/预测/库存/批次）、问答、澄清追问、运营简报 Markdown 生成与下载；无密钥时明确"未调用大模型" | **真实大模型未接通**，当前仅本地规则规划器；不伪造 AI 结论、不泄露密钥、不提供写操作 |
| M6 验收证据 | 58 项 API 自动化测试（本轮全通过）；17 项关键验收断言 JSON；运行日志；页面截图由前端组提供 | 证据在 `03_测试与验证/系统测试/runs/20261029_prototype/`；"通过"仅指本轮实测，不等于老师审核通过 |

## 2. 环境与启动命令

- 解释器：系统 Python **3.12.10**（Windows 10 x64）。
- 已实测依赖：pandas **3.0.5**、numpy 2.5.3、lightgbm 4.6.0、openpyxl 3.1.5、FastAPI 0.115.6、uvicorn 0.32.1、pydantic 2.10.4。
- 本机受限环境把固定版本 wheel 解包在 `电商运营系统/.pydeps/`（由 `api/__init__.py` 自动加入 `sys.path`），无需安装即可启动；正常机器按 `requirements.txt` 安装。

```powershell
cd 电商运营系统
python run.py                     # 默认 http://127.0.0.1:8777
python run.py --port 8780         # 指定端口（测试用随机空闲端口）
# 或：启动系统.cmd / 启动系统.ps1
```

- 唯一正式入口是 `run.py`（FastAPI + uvicorn）；旧 `server.py` 仅作历史对照，不再默认启动。
- 接口文档：`http://127.0.0.1:8777/docs`；机器可读：`/openapi.json`（与实际注册路由一致，见验收 JSON `contract.openapi`）。
- 首次启动自动创建 `runtime/app.sqlite3`（状态库：账号/会话/批次/任务/库存/AI 记录）。

## 3. 账号初始化方式

- 首次启动自动创建 **1 个管理员 + 1 个运营账号**。未配置口令时生成随机口令，写入 `runtime/initial_admin.txt`（一次性初始化材料，请勿提交版本库；删除该文件不影响已有账号）。
- 也可在首次启动前仅在本机设置环境变量指定初始口令（≥8 位）：

```powershell
# 如需自定义初始口令，请仅在本机设置 ECE_ADMIN_PASSWORD 环境变量。
# 如需自定义初始口令，请仅在本机设置 ECE_OPERATOR_PASSWORD 环境变量。
python run.py
```

- 口令以 PBKDF2-HMAC-SHA256 哈希保存；登录会话 token 只存 SHA-256 摘要；改密会撤销该用户其它会话。
- 本仓库/文档不含任何真实口令；测试使用固定口令只注入临时隔离环境（`ECE_RUNTIME_DIR` 指向 `.tmp/`）。

## 4. 无密钥配置样例（AI 未配置）

复制 `.env.example` 为 `.env` 后按需修改；**不要提交含真实密钥的 `.env`**。未配置 AI 密钥时（推荐首次演示状态）：

```ini
# 服务监听
ECE_HOST=127.0.0.1
ECE_PORT=8777

# 数据与状态文件（可省略，默认见 config.py）
# ECE_RUNTIME_DIR=runtime
# ECE_ORIGINAL_DB=runtime/retail.sqlite3
# ECE_APP_DB=runtime/app.sqlite3

# 首次初始化账号（不设置则随机生成并写入 runtime/initial_admin.txt）
# ECE_ADMIN_USER=admin
# ECE_ADMIN_PASSWORD=
# ECE_OPERATOR_USER=operator
# ECE_OPERATOR_PASSWORD=

# 大模型（OpenAI 兼容）。三项齐全才会真正调用；缺任何一项都视为"未配置"。
# ECE_AI_BASE_URL=https://api.example.com/v1
# ECE_AI_API_KEY=
# ECE_AI_MODEL=
# ECE_AI_TIMEOUT=60
```

未配置时 `/api/ai/status` 返回 `llm_configured=false, key_present=false, provider=local-rule-planner`，问答结果显式注明"未调用大模型"，数字全部来自服务端只读工具；密钥不出现在任何前端、日志、导出或接口响应中（已用"密钥注入不泄露"用例验证）。

## 5. 数据说明入口

- 原始数据：[online_retail_II.xlsx](../20261014_电商数据与页面选型/online_retail_II.xlsx)，只读、保持原位；SHA-256 `bcbe73b35f5b7babf197fb0cb983a11f5d9ff929078d4aa53d171b1f2df2e980`。
- 规模与口径：1,067,371 行原始明细；正向销售 1,022,290 行；覆盖 2009-12-01 至 2011-12-09；政策版本 `cross-sheet-multiset-v1-sales-v2-invoice-order`。
- 分析缓存：`电商运营系统/runtime/retail.sqlite3` + `runtime/data_manifest.json`；导入批次各自独立：`runtime/batches/<batch_id>/data.sqlite3`。
- 数据清单可在页面/接口查看：`GET /api/options` 返回 `manifest`、国家、商品与预测方法；`GET /api/imports/batches` 返回当前批次与覆盖范围。
- 历史对照基线（含首尾日、全店）：**851,403 件 / 1,694,068.71 GBP / 2,913 订单 / 86,861 正向明细**；M0 复核记录见 [m0_baseline.md](../03_测试与验证/系统测试/runs/20261029_prototype/m0_baseline.md)。
- 口径边界：金额单位为 GBP，"销售额"不是利润；数量按正向销售口径，金额只汇总有效非负单价；无记录日补 0 仅用于构造连续序列，不代表不营业或需求为 0。

## 7. 已知限制（原型阶段）

1. **真实 AI 未接通**：只能标"待真实 API 验收"。本地规则层按关键词映射只读工具，个别多指标问题可能只命中单个工具（如只返回订单列表而未同时汇总销量与销售额）；30 题样本是固定抽样，不是完整人工审核题集，真实模型下的工具选择率/参数正确率尚未验收。
2. **依赖版本口径**：本机实测 pandas **3.0.5**，而 `requirements.txt` 仍声明 `pandas>=2.2,<3.0`；其他机器按 requirements 安装为 pandas 2.x 时需重新核对历史窗口数字（本机复核一致）。该声明未同步一事已上报 Lead。
3. **导入为原型级快照**：整批快照 + 显式切换，不做跨文件增量合并、不做导入历史回滚界面；`.xls` 不支持（缺 `xlrd`），请用 `.xlsx`/`.csv`。
4. **性能未做完整 P95**：仅记录单次耗时；未按每类接口 ≥100 次采样、5 并发用户的口径验收，也未区分首次与预热。
5. **模拟库存不是真实库存**：商品需求为人工输入，不由预测自动分摊，不产生财务结论。
6. **报告与文档**：前三章参考稿仍是旧技术表述，报告后文章节、接口文档定稿、答辩 PPT、封面与提交信息未随原型更新；老师反馈与最终提交要求待收集。
7. `openapi` 中还注册了契约表未列出的 `GET/PUT /api/settings`（系统设置，非密钥），契约需同步确认。
8. 交易明细行沿用既有契约不含 `customer_id`，订单 CSV/交易 CSV 各自字段以契约第 5.3 节为准。
