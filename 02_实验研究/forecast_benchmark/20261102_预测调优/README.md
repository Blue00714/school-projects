# 预测调优

问题：核对2011-12-03至12-09起点窗口46.1% WAPE及误差方向，并在统一系统数据口径下改善可推广的预测。

主指标：验证目标期WAPE；辅助MAE、BIAS_PCT。所有候选预测必须只用起点以前可见数据，保留异常大单；完整7天窗口与部分窗口分开。

选择期：验证目标日期2011-08-16至10-14，起点须保证全部7个目标在该期内。2011-10-15至12-09为已看过的历史测试期，只作冻结候选后的回溯比较，不能宣称全新盲测。末端46.1%窗口为事后诊断，不用于选参数。

比较：现有组合、4周同星期基准、近期周季节/趋势及少量组合候选；不做大规模调参。无验证收益则保留现有默认并明确报告。保持原始Excel和已有结果不改。最初8个候选未优于原组合，随后基于验证结果补充树模型规则及75%树模型组合，共10个候选；属于本轮验证期调优，不冒称预先注册的最终方案。

实现及运行记录保存在本包，业务必要改动在原系统文件内。

## 实测结论

46.06%的末端窗口整体是低估：BIAS_PCT=-44.83%。2011-12-09实际销量93980件，在21条可评分预测中出现6次，其误差贡献约76.1%。该窗口无完整7天起点，不能代表整个测试期效果。

| 方案 | 验证期WAPE | 后续完整窗口WAPE | 原末端部分窗口WAPE |
|---|---:|---:|---:|
| 原组合 blend_rule | 33.75% | 20.60% | 46.06% |
| LightGBM加历史零销量星期规则 | 30.26% | 20.39% | 49.01% |
| 同星期几4周均值 | 37.13% | 22.08% | 42.96% |

验证期378条（54完整起点）；后续期350条（50完整起点），预测目标均在指定分区内；末端期21条（7尝试起点、0完整起点）。各方案同表同列使用相同目标配对，日期与逐条预测见CSV。原系统旧验收采用不同起点集合，不能把本表20.60%与旧23.34%当成新模型提升。

验证优胜候选将验证WAPE降低3.48个百分点，但后续只改善0.21个百分点且偏差从-5.44%变为-7.67%；原末端窗口变差。因此保持原组合默认，增加可手动比较的`lgbm_rule`候选，版本`daily-v2-lgbm400-rule`。不声称已经改善用户指出的末端46.1%窗口，也不根据这段调低或调高全局预测系数。

去掉12月9日的敏感性分析得到原模型末端WAPE22.48%，仅解释误差集中来源；正式结果保留该日及全部异常订单。
